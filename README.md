One line: the resignation letter an employee actually sends on the way out.

> I hereby resign: the office plant has now outlived three managers, and I refuse to be the fourth.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (97 characters, within the 140-character gate) and prints it. No network, no input, no dependencies.
